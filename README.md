## What I'm building

### [Slug](https://kyle-marks.github.io/slug-beta/)

A macOS Markdown workspace with a terminal built in. It's a side project I use every day as a product manager to draft documents, think through messy problems in text, and turn ideas into flow diagrams and quick HTML prototypes with AI coding agents.
